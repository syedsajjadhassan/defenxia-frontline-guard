# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

Only the latest code on the `main` branch is supported. Older snapshots are
not patched.

## Reporting a vulnerability

DEFENXIA protects people from fraud, so security reports are taken seriously.

**Please do not open a public issue for a security vulnerability.** Instead,
contact the maintainer privately through GitHub — open a draft security
advisory on this repository, or message the maintainer
(@willparker0027-ctrl) on GitHub.

Please include:

- What the issue is and where it is (file / feature)
- Steps to reproduce it, if you can
- What an attacker could do with it

You will get a reply as soon as the maintainer can review it. Once a fix is
ready, it will be released and credited in the release notes unless you ask
to stay anonymous.

## Scope

In scope: the app-lock and authentication code, the scanners (QR, website,
SMS, WiFi), OTP handling, and anything that touches user data or payments.
