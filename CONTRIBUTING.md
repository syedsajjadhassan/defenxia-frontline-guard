# Contributing to DEFENXIA — Frontline Guard

Thank you for helping make digital safety simpler for first-time smartphone
users. Contributions of any size are welcome.

## How to contribute

1. Fork the repository and create a branch from `main`.
2. Make your change in small, focused commits.
3. Run the checks before opening a pull request:
   ```sh
   npm run lint
   npm run build
   ```
4. Open a pull request with a short description of what changed and why.

## What helps most

- Fixes for the scanners (QR, website, SMS, WiFi) and OTP security
- Simpler, clearer screens for low-literacy users
- Hindi / Hinglish strings where they make the app easier to use
- Bug fixes with steps to reproduce the bug

## Ground rules

- Keep the app simple: if a feature needs a long explanation, it is probably
  too complicated for the people this app is for.
- Do not add trackers, ads, or paid features.
- Do not submit fake stars, downloads, or usage numbers — every number in
  this project must be real and verifiable.
- Security issues go through [SECURITY.md](SECURITY.md), not public issues.
